Сайт студии хореографии «Пируэт»

Как открыть:
  Дважды кликните index.html — сайт откроется в браузере. Сервер не нужен.

Файлы:
  index.html      — главная
  about.html      — о студии
  classes.html    — направления
  schedule.html   — расписание (фильтр по направлению)
  prices.html     — абонементы
  gallery.html    — галерея (просмотр по клику)
  contacts.html   — контакты и форма записи
  assets/css/styles.css — стили и токены фирменного стиля
  assets/js/main.js     — вся клиентская логика

Заявки с формы сохраняются в localStorage браузера (ключ plie_applications).
Посмотреть их можно в консоли браузера:
  JSON.parse(localStorage.getItem('plie_applications'))

Где подставить реальные фото:
  Сейчас вместо фотографий — аккуратные графические заглушки (без чужих изображений).
  Чтобы поставить свои снимки, замените блоки .teacher__photo и .gallery-grid figure
  на <img src="assets/img/ваш-файл.jpg" alt="...">.

Название студии («Пируэт»), адрес, телефоны и цены — условные, меняются поиском по тексту.
